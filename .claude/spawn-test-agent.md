# Test Agent Spawner

## 빠른 실행 가이드

테스트 에이전트를 실행하려면, 나에게 다음과 같이 요청하세요:

---

### 📝 요청 템플릿

```
[기능명] 기능에 대한 E2E 테스트 에이전트를 실행해줘.

테스트할 파일:
- [파일 경로 1]
- [파일 경로 2]

주요 시나리오:
- [시나리오 1]
- [시나리오 2]
- [시나리오 3]
```

---

### 🚀 실제 사용 예시

#### 예시 1: 간단한 요청
```
게임 생성 화면 E2E 테스트 에이전트 실행해줘.
```

#### 예시 2: 상세한 요청
```
QR 스캔 기능 E2E 테스트 에이전트를 실행해줘.

테스트할 파일:
- QRScannerScreen.kt
- QRViewModel.kt

주요 시나리오:
- 카메라 권한 요청 및 허용
- 유효한 QR 코드 스캔
- 잘못된 QR 코드 스캔
- 스캔 후 방 참여
```

---

## 🎯 에이전트가 자동으로 하는 일

1. **코드 분석**
   - 관련 파일 읽기
   - 기능 이해
   - UI 구조 파악

2. **시나리오 작성**
   - 사용자 관점의 플로우
   - 정상/비정상 케이스
   - 엣지 케이스

3. **테스트 코드 작성**
   - Compose UI Test 문법
   - Mock 활용
   - 기존 스타일 유지

4. **테스트 실행**
   - Gradle 빌드
   - 에뮬레이터에서 실행
   - 결과 수집

5. **리포트 생성**
   - 성공/실패 통계
   - 발견된 버그
   - 개선 제안

---

## ⏱️ 예상 소요 시간

| 기능 복잡도 | 예상 시간 |
|-----------|----------|
| 간단한 화면 (1-2개 버튼) | 5-10분 |
| 중간 화면 (여러 입력, 플로우) | 10-20분 |
| 복잡한 플로우 (다중 화면) | 20-30분 |

---

## 📊 에이전트 실행 중 확인 방법

### 방법 1: 자동 알림 대기
- 에이전트가 완료되면 자동으로 알림이 옵니다
- 별도로 확인할 필요 없음

### 방법 2: 진행 상황 확인 (선택사항)
```
테스트 에이전트 진행 상황 보여줘
```

---

## ✅ 완료 후 할 일

1. **테스트 결과 확인**
   - 성공/실패 개수
   - 실패 원인 분석

2. **테스트 코드 리뷰**
   - 생성된 테스트 코드 확인
   - 필요시 수정

3. **버그 수정**
   - 발견된 버그 픽스
   - 테스트 재실행

4. **다음 기능 개발**
   - 병렬로 진행 가능!

## 💡 팁

### Tip 1: 구체적으로 요청하기
❌ "테스트 만들어줘"
✅ "로그인 화면 E2E 테스트 에이전트 실행해줘"

### Tip 2: 파일 경로 제공하면 더 빠름
```
게임 맵 화면 테스트 에이전트 실행해줘.
파일: GameMapView.kt
```

### Tip 3: 여러 에이전트 동시 실행 가능
```
1. 게임 생성 화면 테스트 에이전트
2. QR 스캔 기능 테스트 에이전트
두 개 동시에 실행해줘.
```

## 🐛 문제 해결

### 테스트 실패 시
1. 에이전트가 리포트에서 실패 원인 분석해줌
2. 제안된 수정 사항 확인
3. 코드 수정 후 재실행

### 에이전트가 멈춘 것 같을 때
```
테스트 에이전트 상태 확인해줘
```
